# SquadVoice v1.2.9 — LiveKit Cloud Infrastructure Update

This release updates SquadVoice's voice-room backend with refreshed LiveKit Cloud credentials and production infrastructure.

## What's new

- Migrates voice rooms to the updated LiveKit Cloud cluster for reliable WebRTC voice connections.
- Carries over all Ropebound 3D painterly visuals, runner customizations, and graphics settings.
- Maintains low-latency squad voice audio and in-room player coordination during gameplay.

## Install

Download `SquadVoice-v1.2.9.apk` and install it on Android 8.0 or newer. This is a direct APK distribution, not a Google Play release.
