# SquadVoice v1.2.7 — Ropebound 3D improvements

This update improves the Ropebound 3D lobby and gameplay experience.

## What's new

- Shows player online status and improves player management in the lobby.
- Refines Ropebound 3D movement input and the in-game scene.
- Improves game-core and route handling for smoother, more stable multiplayer play.
- Polishes the voice-room/game presentation and transitions.

## Install

Download `SquadVoice-v1.2.7.apk` and install it on Android 8.0 or newer. This is a direct APK distribution, not a Google Play release.
