# SquadVoice v1.2.8 — Ropebound painterly 3D update

This update refreshes Ropebound's playground with a more illustrated, textured look.

## What's new

- Adds painterly sky, terrain, water, and stone textures to the 3D environment.
- Refreshes runner, rope, obstacle, and hazard visuals for clearer gameplay.
- Adds Auto, Low, Medium, and High graphics quality choices to balance detail and performance.
- Keeps the existing voice room active while the team plays Ropebound.

## Install

Download `SquadVoice-v1.2.8.apk` and install it on Android 8.0 or newer. This is a direct APK distribution, not a Google Play release.
