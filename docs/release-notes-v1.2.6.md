# SquadVoice v1.2.6 — Ropebound movement controls

This update fixes the held movement controls in Ropebound and clarifies the control direction for each camera view.

## What's new

- Fixes the left/back and right/forward hold buttons so their pressed state reaches the live game server.
- Changes the movement arrows with the camera: horizontal arrows in FOLLOW view and vertical back/forward arrows in TOP view. The actions remain backward and forward along the course.
- Renames the voice-room game entry from Ropebound 2D to Ropebound 3D.

## Install

Download `SquadVoice-v1.2.6.apk` and install it on Android 8.0 or newer. This is a direct APK release, not a Google Play release. The APK is signed with the same key used by this build host's previous versions.
